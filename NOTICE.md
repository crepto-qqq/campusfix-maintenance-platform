# Public source portfolio notice

This repository contains an authorised public source snapshot of a University of Sydney team project, replacing the earlier documentation-only portfolio. Team members' authorship is retained; publication does not transfer ownership of their contributions to Tian Liao.

The import excludes real credentials, local environment files, databases and user records from every retained commit. Caches, build outputs, private reports/presentations and decorative media without established redistribution provenance are also excluded.

Synthetic test addresses are retained to preserve distinct user identities. Other private contact addresses are anonymised consistently. Author and committer email addresses are replaced; names, dates and relevant messages remain. The resulting commit hashes differ from the school history.

The Gradle wrapper retains its original licence and copyright notices. Other dependencies are resolved by the build tool rather than copied into this repository. See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

No new licence is granted for team-authored code merely by making this portfolio public. The school repository remains access-controlled. Its committed snapshot and the manual refresh boundary are recorded in [SOURCE_ORIGIN.md](SOURCE_ORIGIN.md).
